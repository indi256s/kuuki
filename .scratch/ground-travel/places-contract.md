# Города и метрики: контракт triage

Date: 2026-10-13
Status: resolved

Основание — [исследование](./places-research.md), принятые ответы владельца
о ручном городе, уникальных городах и времени поезда. Это контракт для будущей
реализации, не загруженная база или работающий поиск.

## Источник и поиск

GeoNames `cities500` — глобальная основа. Импортируются страны, доступные
названия регионов и RU/EN-алиасы из `alternateNamesV2`, отфильтрованные по ID
выбранных мест. Региональные дополнения не обязательны для первой версии.
Каталог не гарантирует полноту небольших пунктов или перевод каждого названия.

Поиск идёт по собственной индексированной базе Kuuki; внешний GeoNames API,
публичный Nominatim и загрузка полного каталога в браузер не требуются.
Точные таблицы/индексы относятся к контракту хранения. Ограниченный префиксный
поиск проверяется по плану запроса и числу прочитанных строк; скан всего каталога
на каждое нажатие клавиши недопустим. Ошибка поиска различима с отсутствием
результата и не стирает уже введённое.

## Идентичность и отображение

- Ссылка на каталог — источник и `geonameId`, а не текст названия. Разные места
  с одинаковым названием не объединяются автоматически.
- Выбор показывает название, страну и доступный регион. Для RU/EN используются
  языковые названия, затем исходное имя. ASCII-транслитерация не считается
  английским переводом. Исторические алиасы подходят для поиска, но не заменяют
  текущее название без выбора владельца.
- Координаты WGS84 и IANA timezone сохраняются с источником и версией каталога.
  Отсутствующее/невалидное значение остаётся неизвестным. Часовой пояс не
  заменяется фиксированным UTC-смещением или поясом устройства.
- Точка маршрута имеет собственную идентичность и порядок, даже при одинаковом
  `geonameId`. Тбилиси → Карс → Тбилиси — три точки и два расчётных участка,
  но два уникальных города.
- При обновлении каталога выбранные название/координаты в записи не меняются
  молча. Удаление ID из выгрузки не удаляет путешествие; исправления принимаются
  явно. Станции остаются необязательными деталями железнодорожного участка.

## Ручное место — принято владельцем

Название и страна обязательны; координаты и timezone необязательны. Место имеет
собственный ID владельца и доступно для повторного выбора в его путешествиях.
Одинаковый текст сам по себе не доказывает одинаковую идентичность. Связь с
каталогом или другим ручным местом уточняется явно, без автоматического слияния.

Нет координат хотя бы одной точки — полная оценка неизвестна. Сохранение
доступно; известные точки можно показывать на карте, но не соединять через
пропущенное место как будто маршрут полон. Ручные места другого владельца
не раскрываются через поиск.

## Метрики — приняты владельцем

Роуд-трипы: уникальные ID городов во всех совершённых маршрутах выбранного
периода, включая старт. Повтор/возврат не увеличивает счётчик. План/отмена
не участвуют; количество точек маршрута — другой показатель.

Поезда: сумма известной длительности участков на самих поездах, без ожидания
пересадок. Если известна только часть, показываются известная сумма и покрытие
участков; неизвестное не считается нулём. Время из билета остаётся расписанием,
не доказательством фактического времени. Из локальных часов без необходимых
дат/часовых поясов длительность не выводится.

Инженерное правило годового отнесения: по известной дате начала путешествия
(первый железнодорожный участок или старт роуд-трипа). Путешествие через Новый
год считается один раз в году начала; участки не дробят главный счётчик.
Если начало неизвестно, год не выводится из даты другой остановки: запись
остаётся в общих итогах без года, как в GT-10.

## Допуск реализации

Генератор фиксирует дату/SHA-256 исходников, правила отбора и воспроизводимый
результат; исходные ZIP не загружаются во время пользовательского ввода.
Сохраняется атрибуция GeoNames/CC-BY 4.0. Полная размерность базы, RU/EN-поиск,
индексы и лимиты D1 проверяются на сгенерированном наборе до включения функции.
Импорт удалённой D1 не поручен triage и следует отдельным release gates.
