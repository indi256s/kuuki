## Численные измерения

[literal-contrast.json](literal-contrast.json) содержит 48 пар: непрозрачные sRGB `--mark-*`, `--cat-*`, `--heat-N` против `--surface` и `--heat-N-text` против ячейки. Считался относительный luminance WCAG, `(Lmax + 0.05) / (Lmin + 0.05)`. Собраны все точные блоки `:root` по порядку и поверх них все точные `:root[data-theme='dark']`; простые `var()` разрешены рекурсивно. Использован акцент Shu по умолчанию.

Ограничения измерений: не учитываются прозрачность, соседние сегменты, фактический фон каждого элемента, CSS relative colors / color-mix, индивидуальная поверхность бренд-панели и другие акценты. Это численные значения, не verdict WCAG.

Подтверждены слабоконтрастные значения, уже описанные в `DESIGN.md:112` и `.scratch/overview-redesign/issues/01-palette-contrast.md`: Other light 1.919; Unknown light 1.210 / dark 1.284; dark heat-3 2.275 / heat-4 1.392 против поверхности карточки. Существующее исключение нельзя называть новой найденной ошибкой или общим разрешением на любую слабоконтрастную палитру.

## Основание для будущих критериев

[W3C, Use of Color](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html): цвет не должен быть единственным способом передачи значения или состояния.

[W3C, Non-text Contrast](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html): существенные графические объекты и индикаторы состояния оцениваются относительно соседних цветов; для понимания графика может требоваться различимая граница между сегментами. Подписи, значения и альтернативное представление влияют на оценку. Проверка только «цвет против общего фона» недостаточна.

Практическое следствие для обсуждения: отдельно определить контракты текста, поверхности/контрола, значимых данных, декоративной модели, выбранного состояния и ослабленного baseline. Не обещать, что одна палитра автоматически удовлетворит все эти роли.

## Уточнение после четвёртого раунда, 2026-10-12

Повторная узкая read-only проверка `color_charts_svg` (`gpt-6-luna`, reasoning `max`) установила:

- Месячная шкала: `sections/rhythm/helpers.ts:1–4` вычисляет `min(4, ceil(4 * value / max))` для положительных конечных значений и положительного max. Диапазоны: (0,25%], (25,50%], (50,75%], (75,100%], с верхним ограничением 4. Нулевые/неконечные входы сейчас сводятся к 0; будущий контракт Q16 требует отличать настоящее отсутствие данных от известного нуля там, где источник позволяет это различить.
- Месячный max берётся из всей базы журнала отдельно для flights/distance/duration: `sections/rhythm/section.tsx:52–68`, `packages/shared/src/overview/rhythm.ts:46–53`.
- Карта и country-list используют уже фиксированные visit buckets 0 / 1 / 2–3 / 4–9 / 10+: `lib/map-buckets.ts:3–8,19–27`. Заливки смешивают accent с map-land в долях 24/43/65/90%: `styles.css:83–91`. Это иная абсолютная шкала, чем будущая daily flight heat 0 / 1 / 2 / 3 / 4+.
- Bump сравнивает пять сущностей из последних шести датированных лет текущего scope; фильтр может сменить cohort. Airport/route colors пока назначаются по позиции сущности в scoped cohort: `sections/rankings/section.tsx:50–85`, `packages/shared/src/overview/rankings.ts:77–107`. Это расходится с будущим принятым Q17 о стабильности цвета при смене фильтра.
- Ghost baseline Bump вычисляется независимо из всего журнала, затем обрезается до scoped years; его cohort может отличаться от cohort отфильтрованного сравнения: `sections/rankings/section.tsx:45–49,323–330`. Нейтральный baseline должен сохранять явную подпись своей базы; совпадение ранга не означает совпадение сущности.

## Финальная проверка палитры по Q25, 2026-10-12

Пользователь попросил выбрать лучшую рекомендацию после проверки. В standalone образце скорректирована только категорийная светлота; пять исходных акцентов, нейтральные поверхности и heat-значения сохранены. Исходники и зависимости приложения не менялись.

- Color.js 0.7.1: 366 объявленных непрозрачных пар проходят текст ≥4.5 и mark/contour ≥3; минимумы 4.6514 и 3.1569 соответственно. 120 heat-fill/background пар остаются наблюдениями без общего pass. [Полные пары](palette-measurements.json).
- Machado, авторские матрицы severity 1.0, linear RGB: все пары внутри makers/regions/пяти comparative наборов в двух режимах. Минимальная дистанция OKLab×100 каждого набора выросла; это сравнительная метрика, не критерий доступности. Tritan — приближение опубликованной модели. Сохранены подписи, штрихи, маркеры. [Пары и ограничения](palette-cvd-review.json).
- 40 heat-последовательностей сохраняют порядок светлоты, включая нулевую ступень. Assert-проверки для чёрного/белого/нейтрального серого проходят. Генераторы и анализатор исполняются без новых project dependencies.
- HTML preview 728 px обычный/deutan и 360 px: две панели, пять акцентов, автоматические проверки сохранения identity/sort/state, без console errors и horizontal overflow. Снимки `palette-final-{normal,deutan,mobile}.png` просмотрены после уменьшения до 1200 px.

Проверка относится к самостоятельному образцу. Реальные графики, соседства donut, плотные heat-карты, тонкие SVG-линии, MapLibre, favicon и PNG требуют проверки при переносе. Полный build/production/forced-colors не выполнялись. Итоговая рекомендация — [palette-proposal.md](palette-proposal.md).
