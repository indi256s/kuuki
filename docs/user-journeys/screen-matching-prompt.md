# Промпт для определения текущего экрана

Передай агенту этот текст, текущий скриншот, URL, состояние авторизации, размер окна и путь к папке атласа. Если часть сведений неизвестна, укажи это.

```text
Определи текущее состояние интерфейса Kuuki по приложенному скриншоту и атласу.

Прочитай manifest.json в указанной папке атласа. Сначала отфильтруй состояния по pathname/query, авторизации и desktop/mobile. Одному маршруту соответствуют разные формы, диалоги, фильтры и ошибки.

Для подходящих состояний сравни recognition и snapshot с видимыми заголовками, кнопками, полями, открытыми меню и сообщениями. Открой PNG лучших кандидатов и сравни компоновку. Имена, даты и количества в тестовых данных могут отличаться; форма и режим интерфейса важнее точного совпадения примеров.

source-only не имеет изображения и не подтверждает визуальное совпадение. Для simulated назови условие подмены. Учитывай версию сборки из environment.json: локальный атлас не подтверждает совпадение с опубликованной версией. Если убедительного соответствия нет, верни unmapped, наблюдаемые отличия и ближайших кандидатов. Не придумывай отсутствующие ID или переходы.

Верни JSON. result принимает matched, uncertain или unmapped; confidence принимает high, medium или low. state_id и screenshot равны null, если совпадение не установлено. observed_cues содержит конкретные видимые признаки; differences содержит отличия от кандидата. Элементы alternatives имеют state_id и reason, элементы available_actions имеют label, to и effect из manifest.

Формат ответа:
{
  "result": "unmapped",
  "state_id": null,
  "confidence": "low",
  "screenshot": null,
  "observed_cues": [],
  "differences": [],
  "alternatives": [],
  "available_actions": []
}

Укажи действия, которые доступны в текущем состоянии; disabled-кнопки не являются переходами. Определение экрана само по себе не запускает действия в приложении.
```
