# Общий паспорт и явное расширение публикации

Паспорт объединяет личность путешественника и подтверждённые страны из
перелётов, наземных поездок и ручных отметок, но общий интерфейс не даёт права
автоматически расширять существующую публичную проекцию. Владелец явно
включает публикацию всех подтверждённых стран с предпросмотром; до этого
старые публичные профили сохраняют прежний состав, а отключение возвращает
его. Даты, частота посещений, заметки, источники и маршруты остаются приватными,
чтобы добавление нового вида путешествий не раскрывало ранее закрытые сведения.

Это принятое решение из [интервью](../../.scratch/passport-profile/spec.md)
(Q5, Q18–19, Q25), ещё не реализация. Публичные карточки, карта, поиск и общий
счётчик используют только разрешённую проекцию; View as visitor читает её,
а не скрывает приватные поля оформлением. Публичность профиля и участие
в авиационных рейтингах сохраняют отдельные границы согласия.

Принятое последующее уточнение Q28: скрытие страны исключает её из карточек,
карты и публичного состава Паспорта, сохраняя исходные записи и фактическую
статистику. Такое скрытие обратимо и не обещает убрать страну с других
публичных поверхностей, например авиационного Обзора.

## Реализация (15 октября, ветка `feat/passport-unified`)

Миграция `0013_unified_passport.sql` добавляет `passport_hidden_countries` и
`profiles.passport_publication` (`flights` по умолчанию; удалённый D1 требует
отдельного разрешения по runbook). Публичная проекция и предпросмотр владельца
используют одну функцию `projectPublic` в `publicProfiles.ts`: `flights`
сохраняет прежний состав, `all` берёт подтверждённые страны любых источников,
скрытые исключаются в обоих режимах, наружу выходят только коды стран.
View as visitor (`/passport?as=visitor`) и предпросмотр в Settings читают эту
проекцию. Скрытие (`PUT`/`DELETE /api/passport/hidden/:cc`) не трогает
производные данные; Обзор читает паспорт без учёта скрытия.

Известная особенность: режим `flights` унаследовал правило, по которому страна
с одним лишь ожидающим перелётом публикуется, если её аэропорт есть в публичном
наборе маршрутов. Режим `all` ожидающие страны не публикует.
