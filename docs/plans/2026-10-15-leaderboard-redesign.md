# Leaderboard Redesign Implementation Plan

Goal: `/leaderboard` becomes a departures board: eight category gate tiles showing the viewer's place (five sky, three ground), a "This year / All time" period, a sarcastic narrator line, a top-three podium, and a board of top rows plus the viewer's neighbourhood, backed by a corrected cache.
Architecture: Data first. A rebuilt `leaderboard_cache` (period column, eight categories, `RANK()` ties, `is_public` in the rebuild) feeds one page read that returns every category × period at once; the page switches category and period on the client. Two shared primitives are extracted from existing callers (split-flap from Journal Next up, gate tile from the profile) before the leaderboard UI consumes them.
Success: no rank gaps for hidden profiles; equal values share a place; ground categories rank only members who publish all countries and have ≥ 3 completed ground journeys; category and period switches never show a skeleton; rank up flips the tile once per publication; all existing cache readers keep returning all-time sky rows only where they did before; `pnpm verify:cloudflare` passes.
Out of scope: ground distance or hours; friends boards and "Compare with me"; seasons other than the calendar year; remote D1 migration, deploy and production checks (separate authority via `deploy-kuuki` and `docs/runbooks/audit-remediation-release.md`); Paper boards.
Constraints: Run from the workspace root. Shared checkout: follow `docs/agents/shared-checkout.md` before any commit; preserve others' dirty files (`import/*`, docs, scripts are currently modified by other owners). No new UI dependency and no shadcn; primitives live in `apps/next/src/client/ui/` (Arc free items, `docs/research/2026-10-08-arc-source-inventory.md`). DESIGN.md owns tokens and contrast; no divider lines inside cards; copy EN + RU via `glados-copy`, sarcastic where witty, calm in trust contexts. Motion values from `~/.claude/docs/motion-durations.md` and the spec's Motion table. Playwright runs once, at the end. Execution preferences: Sonnet subagents for spec-driven wave work, one at a time unless waves are marked parallel-safe; the primary checks each wave itself (no per-wave reviewer); one final review on GPT-6.1 Sol at `high` through T3 `delegate_task` (omit `runtimeMode`); any UI/animation audit on Sonnet.
Planning basis: `.scratch/leaderboard-redesign/spec.md` (2026-10-15, Components and Motion sections included). Repository evidence at base `79d37815`: `db/migrations/0001_init.sql:262-273` (`leaderboard_cache` CHECK on five categories, `UNIQUE(user_id, category)`); `functions/api/_services/leaderboard.ts` (rebuild omits `is_public`, `ROW_NUMBER` tie-break by `created_at`, `ROWS_PER_INSERT = 14` for 7 binds); `workers/maintenance/index.ts:76` (rebuild runs in the 5-minute maintenance pass); cache readers `functions/api/_services/publicLeaderboard.ts`, `functions/api/me/rankings.ts`, `functions/api/leaderboard/total-users.ts`, `functions/api/_services/publicProfiles.ts:117`, `apps/next/src/server/profile.ts:46`, and `functions/api/_lib/users.ts:98` (account deletion); `db/migrations/0011_ground_travel.sql` (`ground_journeys.mode/status/start_date`, `ground_journey_countries`); `db/migrations/0013_unified_passport.sql` (`profiles.passport_publication`); ADR 0005 and ADR 0007; `apps/next/src/client/journal/next-up.tsx:87` (private `Flap`); `apps/next/src/client/profile/profile.css:360` (`.profile-gate`); `apps/next/src/client/ui/segmented-control.tsx`; `apps/next/src/client/profile/ladders/copy.ts:20` ("Countries on flights" / "Страны в перелётах"); `scripts/smoke-next-runtime.ts:490-502` (single ranked fixture). ## W1: Corrected cache, ground categories, one page read

Objective: the cache ranks correctly, knows periods and ground categories, and one read returns everything the page needs, while every existing reader keeps its current meaning.

Owned writes: see execution map. `client/leaderboard/categories.ts` transfers to W3 after W1 is accepted.

Implementation:

- **Migration `0014_leaderboard_periods.sql`.** Rebuild `leaderboard_cache` (SQLite cannot alter a CHECK): create the new table, drop the old, rename. The cache is fully rebuilt every pass, so no data copy is needed; the first maintenance pass after migration repopulates it. Columns add `period TEXT NOT NULL CHECK (period = 'all' OR period GLOB '[0-9][0-9][0-9][0-9]')`; `category` CHECK lists the eight keys (`flights, distance, countries, cities, airlines, rail, road, ground_countries`); `UNIQUE (user_id, category, period)`; index `(category, period, rank)`. Keep `ON DELETE CASCADE` so account deletion (`_lib/users.ts:98`) still works. Follow the existing migration and snapshot conventions in `db/`.
- **Rebuild (`_services/leaderboard.ts`).** Keep the "parity" header but record the deliberate deviations: `is_public = 1` joins the sky eligibility; rank uses competition ranking (`1, 1, 3`) with value ties sharing a rank (no `created_at` tie-break); percentile from the shared rank. Ground eligibility: `is_public = 1 AND show_on_leaderboards = 1 AND passport_publication = 'all' AND` ≥ 3 completed `ground_journeys` (rail + road), published derived state. Ground values: count of completed rail journeys, completed road journeys, distinct `ground_journey_countries.country_code` over completed journeys. Period `YYYY` (current UTC year at rebuild): flights in `('awaiting','logged')` with `date` in that year give count, distance sum, distinct airlines, distinct departure/arrival airports, distinct airport `country_code`s; ground journeys with `start_date` in that year give the ground values. Record in a code comment that year countries come from airport countries (no legacy evidence or transit rules) and therefore can differ from the all-time number. Eligibility thresholds are evaluated on all-time totals in both periods, so a member never drops out of "this year" for having few flights this year; a member with zero in a category for the year is not ranked in that category-year. Recompute the insert chunk from the bind count (8 binds → 12 rows) instead of hard-coding 14. Keep DELETE + INSERTs in one batch.
- **Existing readers keep their meaning.** `publicLeaderboard.ts` reads, `me/rankings.ts`, `server/profile.ts`, `publicProfiles.ts:117` and `total-users.ts` add `period = 'all'`; the profile and public-profile rankings keep sky categories only until a later decision (filter `category IN` the five sky keys), so profile gate tiles do not suddenly grow ground entries. Add `is_public = 1` where a reader lacks it (`me/rankings.ts`, `server/profile.ts`) only if it matches the reader's existing owner semantics; owner-only reads may intentionally show the owner's place regardless, so decide from the current tests and record the choice.
- **Page read.** New `readLeaderboardBoard(db, viewerId | null)` in `publicLeaderboard.ts` returning, for every category × period (`all` and current year): podium (rank ≤ 3, ties included), rows rank 4–10, total, `updatedAt`; and for a viewer: per category × period their entry or eligibility state (`ranked`, `progress {have, need}`, `blocked: publication`, `pending`), neighbourhood (±2 around their rank) and the next-place gap (value of the nearest better rank minus theirs). Paging for "Show all" stays on `GET /api/leaderboard?category&period&offset&limit` (add `period`, default `all`). Keep `readOwnLeaderboardEligibility`/`readOwnLeaderboardRank` exported until W3 removes their callers. `server/public.ts` exposes `getLeaderboardBoard()`.
- **Category labels.** `categories.ts`: rename `countries` to "Countries on flights" / "Страны в перелётах" (same strings as `profile/ladders/copy.ts:20`); add `rail` "Trains" / "Поезда", `road` "Road trips" / "Автопутешествия", `ground_countries` "Countries by land" / "Страны по земле", with units and RU plural forms; add a `group` (`sky` | `ground`) lookup.
- **Fixture.** Extend the leaderboard block in `scripts/smoke-next-runtime.ts` to ~25 ranked members with deterministic values including at least one tie at rank 3, one hidden (private) opted-in member, the signed-in fixture account `a@example.test` outside the top 10, and three members with `passport_publication = 'all'` and completed ground journeys (one road-only). This is what W3 and the final browser lane render.
- **ADR 0007.** Append an accepted refinement: ground leaderboard categories rank only members who publish all confirmed countries; aviation-ranking consent stays separate.

Dependencies: none.

Focused proof:

- rank gaps / ties / ground gate / periods → new `functions/test/leaderboard-refresh.test.ts` against the existing test D1 harness: private opted-in member gets no rank and no gap; equal values share a rank and the next rank skips; `passport_publication = 'flights'` member absent from ground categories; member with 2 completed journeys absent; cancelled and planned journeys ignored; year rows count only that year; insert chunking stays under 100 binds with > 12 eligible members.
- readers keep meaning → `functions/test/public-reads.test.ts` (and the existing `/api/me/rankings` tests) assert only `period = 'all'` sky rows reach profile and public-profile rankings.
- page read shape → one test of `readLeaderboardBoard` for a guest and a ranked viewer outside the top 10 (neighbourhood and gap).
- `pnpm test:api`, `pnpm typecheck:api`, `pnpm typecheck:maintenance` exit 0.

Accept when: the tests above pass; `git diff` shows `period = 'all'` on every pre-existing cache reader; migration applies on the local fixture (`pnpm next:preview` starts and `/leaderboard` still renders the old page with fixture data).

## W3: Leaderboard page

Objective: `/leaderboard` implements the spec: tile strip, period switch, narrator, podium, board with neighbourhood, motion and states.

Owned writes: see execution map.

Implementation:

- **Data flow.** `page.tsx` (server) calls `getLeaderboardBoard()` once and passes the payload to one client component. Category and period live in client state initialised from `?category=` and `?period=`; changes call `history.replaceState` (no navigation, no Suspense keyed on category). Invalid query values fall back to `flights` / `all`. Remove `Ranking`'s per-category fetch, `YourPlace`, the pinned row and the IntersectionObserver pin logic; keep `recordRank` (and `private-rank.test.ts`) as the rank-up source, now called per category with the `all` period.
- **Tile strip.** `<nav>` of links (`href` keeps the query so links still work without JS and open in new tabs; click handler intercepts for client switching), `aria-current="page"` on the selected tile, accessible name "Flights, your place 12" / "Перелёты, ваше место 12" and progress/blocked/guest variants per spec. `GateTile` gains `size="compact"` (72px, 24/28 mono, `tabular-nums`, four-digit min width, press `scale(0.96)`, fine-pointer hover). Desktop two rows with group labels; ≤ 700px one `scroll-snap` strip with edge `mask-image` fades only on scrollable edges and `scrollIntoView({ inline: 'center', behavior: 'instant' })` on load.
- **Period switch.** `SegmentedControl` (`dense`) with "2026" (current year from the payload) and "All time" / "Всё время".
- **Narrator.** A copy table keyed by state (leader, tied, close gap ≤ 2 units, far, not eligible, publication-blocked with Settings link, pending, guest with sign-in link), EN + RU, written with the `glados-copy` skill; numbers interpolated from the payload. Replaces the captions, eligibility paragraph and bottom sign-in line.
- **Podium.** `<ol>` in rank order, visual order 2-1-3 by CSS grid; `--rank-gold/silver/bronze`; ties share a step label; "Free" / "Свободно" signs for missing places linking to Add flight (sky), the ground journey add flow (ground) or sign-in (guest).
- **Board.** `<ol>` with `<li value>`; "Departures" / "Вылеты" or "Отправления" header word; ≤ 20 total → everyone; otherwise ranks 4–10, an `aria-hidden` gap row with a visually hidden "Places N to M" lead-in, then the viewer ±2 with the gap line on the row above; stretched-link rows; "Show all" `Button` pages through `GET /api/leaderboard` 50 at a time and moves focus to the first new row.
- **Footer.** Relative "Updated N min ago" computed once, `<time dateTime>` with absolute `title`.
- **Motion.** Per the spec's Motion table using `SplitFlap`: rank-up flip once per publication when the tile is in view, 60ms between tiles; podium rise #3 → #2 → #1 (200ms `--ease-out`, 60ms apart) on the first hard load per session (sessionStorage flag), settled on client navigation; reduced motion = 150ms linear opacity crossfade for rank up, settled podium.
- **States.** Skeleton shaped as strip + podium; `error.tsx` renders under the heading and a static strip; pending publication keeps last published ranks with the pending narrator line. Remove the "The community" eyebrow.
- **Docs.** Update the DESIGN.md Leaderboard row (line ~127: categories, renamed countries, ground gate) and add the leaderboard motion entries; record any deviation from DESIGN.md there.

- a11y names and order → component tests for tile names (ranked, progress, blocked, guest), podium `<ol>` order, board `<li value>` across the gap, focus to first new row after Show all.
- copy coverage → a test that every narrator state has EN and RU strings.
