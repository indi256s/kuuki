open work using the [issue tracker contract](agents/issue-tracker.md). For new

## Behavioral ownership

Follow these connections before proposing behavior changes; UI rules explain the
server contract but do not replace it. Backend services live under
`functions/api/_services`.

- **Import questions, review and save:** [unified-import.tsx](../apps/next/src/client/import/unified-import.tsx) owns the member route’s multi-file review; [unified-session.ts](../apps/next/src/client/import/unified-session.ts) queues single-source jobs, complements local barcodes with online extraction, retains owning batch IDs, pending online complements and user selections, and confirms each batch with its receipt versions. Check [multi-file/recovery tests](../apps/next/src/client/import/unified-session.test.ts) and [real text admission](../apps/next/src/client/import/unified-admission.test.ts). Manual entry stays on `/add`; legacy source URLs enter the unified surface. Hosted onboarding retains the existing single-source ImportClient. [questions.ts](../apps/next/src/client/import/questions.ts) groups needs using [review-model.ts](../apps/next/src/client/import/review-model.ts); [question-deck.tsx](../apps/next/src/client/import/question-deck.tsx) applies answers inside [review-step.tsx](../apps/next/src/client/import/review-step.tsx). [import-client.tsx](../apps/next/src/client/import/import-client.tsx) connects [draft-saver.ts](../apps/next/src/client/import/draft-saver.ts), [confirm-runner.ts](../apps/next/src/client/import/confirm-runner.ts) and [import-api.ts](../apps/next/src/client/import/import-api.ts). The server owns [draft edits](../functions/api/_services/importDrafts.ts), [conversion](../functions/api/_services/importConversion.ts) and [flight creation](../functions/api/_services/flightCreate.ts); [manual-save.ts](../apps/next/src/client/import/manual-save.ts) uses the shared flight writes. Check [question rules](../apps/next/src/client/import/questions.test.ts), [confirm recovery](../apps/next/src/client/import/confirm-runner.test.ts), [import journey](../apps/next/tests/import.test.ts) and [server conversion](../functions/test/import-conversion.test.ts). For presentation, read DESIGN's [Import dock](../DESIGN.md#import-dock) and [states](../DESIGN.md#interaction-and-states).
- **Shell, navigation and Add:** [shell.tsx](../apps/next/src/client/shell.tsx) composes [nav.tsx](../apps/next/src/client/nav.tsx), [add-menu.tsx](../apps/next/src/client/add-menu.tsx), [avatar-menu.tsx](../apps/next/src/client/avatar-menu.tsx) and the import dock; [queue-summary.tsx](../apps/next/src/client/queue-summary.tsx) (`QueueMenuItem`) and the `MenuTray` in [menu.tsx](../apps/next/src/client/ui/menu.tsx) serve the menus; [add-actions.tsx](../apps/next/src/client/add-actions.tsx) supplies desktop and mobile capture entries. [navigation-link.tsx](../apps/next/src/client/navigation-link.tsx) announces route intent; [gates.ts](../apps/next/src/server/gates.ts) owns member admission. Check the [navigation suite](../apps/next/tests/navigation.test.ts) and [route link tests](../apps/next/src/client/journal-route-links.test.tsx).
- **Ground travel:** [groundJourneys.ts](../functions/api/_services/groundJourneys.ts) validates commands and writes each one as a receipt-first D1 batch; [groundJourneyRead.ts](../functions/api/_services/groundJourneyRead.ts) builds the list, totals and replays; [groundPlaces.ts](../functions/api/_services/groundPlaces.ts) searches the GeoNames catalog and owner manual places; [railTicketOcr.ts](../functions/api/_services/railTicketOcr.ts) reads tickets without storing them. Shared DTOs, metrics and list order live in [groundTravel.ts](../packages/shared/src/groundTravel.ts). The page is [ground-page.tsx](../apps/next/src/client/ground/ground-page.tsx) with [detail-sheet.tsx](../apps/next/src/client/ground/detail-sheet.tsx); forms, drafts and the unified review are in [client/ground/form](../apps/next/src/client/ground/form/journey-form.tsx), OCR in [form/ocr](../apps/next/src/client/ground/form/ocr/rail-ocr-panel.tsx). Confirmed countries feed Passport through `ground_journey_count` in [countryEvidence.ts](../functions/api/_services/countryEvidence.ts). Tests: `functions/test/ground-*.test.ts` and `apps/next/src/client/ground/**/*.test.ts*`.
- **Overview data and charts:** [server/overview.ts](../apps/next/src/server/overview.ts) and the [data endpoint](../functions/api/me/overview/data.ts) share [overviewData.ts](../functions/api/_services/overviewData.ts). [overview-context.tsx](../apps/next/src/client/overview/store/overview-context.tsx) connects filters and preferences to [overview-page.tsx](../apps/next/src/client/overview/page/overview-page.tsx) and its [section registry](../apps/next/src/client/overview/sections/registry.ts). [kuuki-chart.tsx](../apps/next/src/client/overview/charts/kuuki-chart.tsx) owns shared chart interaction and table access. The figures card (a leading total and static illustration, followed by distance, flight time and geography) lives in [hero-panel.tsx](../apps/next/src/client/overview/hero/hero-panel.tsx) and [records.ts](../apps/next/src/client/overview/hero/records.ts), with figure bucket tests in [records.test.ts](../apps/next/src/client/overview/hero/records.test.ts). Records retain sparse facts, personal distance ranges and year evidence; Rankings adds compact flight-length and departure-schedule ratios with lifetime context and local inspection. Aircraft owns maker composition through the adapted Arc waffle with all-flight shares; multi-year desktop Rhythm promotes its year-by-month matrix into the primary History view. Overview has no automatic goal band. Check [data tests](../functions/test/overview-data.test.ts), [context tests](../apps/next/src/client/overview/store/overview-context.test.tsx) and [chart tests](../apps/next/src/client/overview/charts/kuuki-chart.test.tsx).
- **Auth and Concorde:** [auth-card.tsx](../apps/next/src/client/auth-card/auth-card.tsx) connects form, recovery and welcome steps, and renders [concorde-field.tsx](../apps/next/src/client/auth-card/concorde/concorde-field.tsx). [continue.ts](../functions/api/auth/continue.ts) owns the continue decision; [auth.ts](../functions/api/_lib/auth.ts) owns request authentication. For regeneration or previews, use the pinned [Concorde setup](../scripts/concorde/README.md). Check [auth entry](../apps/next/tests/auth-entry.test.ts), [recovery](../apps/next/tests/auth-recovery.test.ts), [Concorde](../apps/next/src/client/auth-card/concorde/concorde-field.test.tsx) and [server auth](../functions/test/auth.test.ts). Read DESIGN's [Auth card](../DESIGN.md#auth-card) and [Motion](../DESIGN.md#motion) for changes to that surface.
- **Google sign-in:** [Better Auth configuration](../functions/api/_lib/betterAuth.ts) owns the optional provider, verified identity linking and private profile provisioning; the [auth dispatcher](../functions/api/auth/[[path]].ts) admits the redirect start and Google callback. [Better Auth integration tests](../functions/test/betterAuth.test.ts) cover OAuth state, account preservation and provider failures. Credentials and live local setup are in [Configuration](../README.md#configuration).
- **Passport, profile and privacy:** one Passport page serves the owner, visitors and the owner's visitor preview (ADR [0007](adr/0007-unified-passport-publication-boundary.md)). [/passport](<../apps/next/src/app/(member)/passport/page.tsx>) reads the owner data in one call ([server/passport.ts](../apps/next/src/server/passport.ts)) or, with `?as=visitor`, the public preview; [/fly/[username]](<../apps/next/src/app/(public)/fly/[username]/page.tsx>) reads the public projection and keeps the closed and missing covers ([view.ts](../apps/next/src/client/profile/view.ts)). [passport-page.tsx](../apps/next/src/client/passport/passport-page.tsx) splits owner and public data, and [passport-layout.tsx](../apps/next/src/client/passport/passport-layout.tsx) renders the shared order: identity, totals, [toolbar](../apps/next/src/client/passport/passport-toolbar.tsx), [cards](../apps/next/src/client/passport/collection.tsx) or [atlas](../apps/next/src/client/passport/atlas/index.tsx), pending, achievements, rankings and the flight block. [model.ts](../apps/next/src/client/passport/model.ts) owns entries, sources, filters, sorting and totals, with URL state in [url-state.ts](../apps/next/src/lib/url-state.ts); the [country sheet](../apps/next/src/client/passport/country-sheet.tsx) holds history, manual marks and Hide, the [hidden list](../apps/next/src/client/passport/hidden-sheet.tsx) restores, and [stamp-hero.ts](../apps/next/src/client/passport/stamp-hero.ts) runs the pointer hero. Server reads: [passport.ts](../functions/api/_services/passport.ts) (owner collection, hidden codes, journey modes) and [publicProfiles.ts](../functions/api/_services/publicProfiles.ts) (the one public projection, gated by visibility, shared with the preview); hiding is [passport/hidden/[cc]](../functions/api/passport/hidden/[cc]/index.ts). [remarks.ts](../apps/next/src/client/profile/remarks.ts) and [unseen.ts](../apps/next/src/client/profile/unseen.ts) own the narrator line and badge baselines; [ladders/model.ts](../apps/next/src/client/profile/ladders/model.ts) maps badge rows to ladders, tiles and the nearest rung, and [ladders/figures/](../apps/next/src/client/profile/ladders/figures/) holds the drawings. [settings-form.tsx](../apps/next/src/client/account/settings-form.tsx) writes profile, privacy and publication changes through [profiles/me.ts](../functions/api/profiles/me.ts); [settings-guard.tsx](../apps/next/src/client/account/settings-guard.tsx) protects unsaved edits. Check the [publication and hide API tests](../functions/test/passport-publication.test.ts), [model tests](../apps/next/src/client/passport/model.test.ts), [page tests](../apps/next/src/client/passport/passport-page.test.tsx), [country sheet tests](../apps/next/src/client/passport/country-sheet.test.tsx), [atlas tests](../apps/next/src/client/passport/atlas/map.test.tsx), [private read tests](../apps/next/src/client/profile/private-reads.test.ts), [settings guards](../apps/next/src/client/account/settings-guard.test.tsx) and the [passport](../apps/next/tests/passport.test.ts) and [settings](../apps/next/tests/settings.test.ts) journeys. Read DESIGN's [Passport](../DESIGN.md#passport) for presentation.
