# Kuuki Brand Guidelines

## Brand Identity

**Name:** Kuuki (Primary), くうき (Brand Atmosphere)

**Tagline:** Your visual legacy of flight

**What Kuuki is:** A personal flight journal for aviation enthusiasts. Log journeys, build your collection, discover patterns.

**Core Concept:** Atmosphere (Kuuki). Weightless, breathable, essential.

## Design Direction

Restrained editorial character with Japanese influence (Ma, Shibui): typography, whitespace, and the details of stamps and tickets carry the design. Warm paper-like light neutrals and charcoal dark neutrals, terracotta accent in both themes. All concrete values, tokens, type, elevation and motion rules are in [DESIGN.md](../../../DESIGN.md).

## Usage Rules

- **Kuuki (Romanized):** Use for standard text, titles, and headers.
- **くうき (Hiragana):** Use ONLY for logo marks or decorative large-scale elements, never for body copy or functional text. It is not a texture: no low-opacity watermarks or gradients.
- **Kanji in functional text:** Don't. Romanized for utility.
- **Monospace:** Only for ticket data (IATA codes, flight numbers, times, table dates, handles); see DESIGN.md.

## Design Principles

1. **Quiet precision.** Present data exactly, on calm surfaces.
2. **Progressive disclosure.** Don't overwhelm; reveal complexity as the user dives deeper.
3. **Warmth over cold.** Avoid clinical blues and grays; lean toward warm stones, inks and paper tones.
4. **Breathable space ('Ma').** Whitespace is active, not empty; avoid dense information.

## Anti-Patterns

| Don't                    | Do Instead                               |
| ------------------------ | ---------------------------------------- |
| Cold/clinical styling    | Warm, restrained neutrals                |
| "Tech" neon blue         | Terracotta accent                        |
| Dense information        | Breathable space, progressive disclosure |
| Kanji in functional text | Romanized for utility                    |
